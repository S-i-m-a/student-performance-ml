# Student Performance Prediction (Decision Tree)
Course 23CSE401 – Fundamentals of AI. Predicts **Pass/Fail** from study hours, attendance, previous score, assignment completion, sleep hours.

> **Dataset: SYNTHETIC** (generated by `src/data.py`, seed 42). It is NOT real student data. No external licence applies.
> Target: `result` = Pass (1) if a hidden final score >= threshold, else Fail (0). The hidden score is not a feature, so there is no target leakage.

## Structure
app.py (Streamlit) · train.py · evaluate.py · src/ (config, data, model) · tests/ · data/ · models/ · figures/ · report/ · presentation/ · demo/

## Setup (Windows / macOS)
```
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # macOS
pip install -r requirements.txt
```
## Run
```
python train.py              # creates data/students.csv + models/model.joblib
python evaluate.py           # prints metrics, saves plots to figures/
python -m pytest tests -v    # or: python -m unittest discover -s tests
streamlit run app.py
```

## Limitations
Synthetic data (results reflect the generator rules, not real students); small dataset; classes are balanced here, but with imbalance accuracy can mislead, so check precision/recall/F1. Predictions are educational estimates only.
